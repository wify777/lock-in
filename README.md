# Lock In — личный наставник фокуса

Веб-приложение, которое через камеру и экран следит, работаешь ли ты, и голосом реагирует на телефон, соцсети, сонливость и уход от задачи.

- Камера обрабатывается локально в браузере (MediaPipe), видео никуда не отправляется.
- Сервер Lock In видит активное приложение и сайт на Mac, включает строгий режим и подключает телефон.
- Учитель разрешает паузы («можно в туалет?»), проверяет объяснение (метод Фейнмана), напоминает про глаза, осанку и воду.
- Умная проверка экрана и учитель через Claude — по желанию, со своим API-ключом Anthropic.

## Запуск (macOS)

```bash
python3 lockin_server.py
```

Открой http://localhost:5173 в Chrome. Чтобы подключить телефон, нажми «📱 Подключить телефон» и отсканируй QR-код (телефон и Mac должны быть в одной сети Wi-Fi).

Сертификат и код подключения телефона сервер создаёт сам в папке `.lockin/`. Её нельзя публиковать, поэтому она в `.gitignore`.

## Файлы

- `index.html` — приложение
- `phone.html` — страница для телефона
- `blocked.html` — страница «Не сейчас» для строгого режима
- `lockin_server.py` — локальный сервер (без сторонних библиотек)
