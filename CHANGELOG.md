# Изменения

## 1.0.0 — 13 ноября 2026

Первый релиз.

**Новое**
- Дизайн «классная доска»: рукописные реплики учителя, итог сессии как бумажный табель с печатью оценки.
- Шаги к цели, перерывы по плану (25 + 5, 50 + 10), экран паузы с таймером.
- Опыт и уровни, 16 достижений, цель на день, карта за 12 недель, подсказки по истории.
- Карточка сессии для скачивания (PNG), копия данных в файл.
- Подключение телефона вынесено на главный экран.
- Режим `?demo` для записи роликов: показывает пример истории, ничего не сохраняет.
- Запуск двойным щелчком: `Lock In.command`.

**Исправлено**
- Телефон: выключенный экран — нормальное состояние; не ругает, когда ты берёшь телефон, чтобы выключить.
- Связь с телефоном больше не зависает от «повисших» соединений.
- Реже ложные «думаешь» и «телефон»; тревога по экрану снимается сразу после закрытия приложения.

**Безопасность** (по итогам аудита)
- Закрыт обход защиты служебной папки через `%2e`: раньше по такому адресу отдавались код подключения телефона и ключ сертификата.
- Сервер проверяет Host и Origin: чужие сайты в браузере больше не могут управлять локальным API.
- Отдаются только три страницы и файл автотестов; заголовки безопасности (CSP, nosniff, запрет встраивания).
- Скрипт QR-кода проверяется по хэшу (SRI); код подключения не пишется в журнал.
