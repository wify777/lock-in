# Безопасность

Lock In работает на твоём компьютере. Наружу он выставляет только страницу телефона (порт 5174, HTTPS, доступ по коду).

## Что защищено
- Локальный API (`http://localhost:5173`) отвечает только на запросы с хостом `localhost` / `127.0.0.1`, принимает POST только в JSON и только с собственного адреса. Чужой сайт в браузере не может им управлять.
- Файлы отдаются по белому списку: `index.html`, `phone.html`, `blocked.html`, `tests/harness.js`. Ключ сертификата и код подключения телефона лежат в папке `.lockin/` и не отдаются никогда.
- Телефон видит только свою страницу; пинги принимаются только с кодом подключения.
- Видео с камеры обрабатывается в браузере и никуда не отправляется. История и настройки хранятся в браузере. API-ключ Anthropic (если ты его ввёл) не попадает в файл копии данных.

## Что важно знать
- Страница загружает библиотеки с CDN (MediaPipe, Tesseract, Anthropic SDK, QR-код). QR-код проверяется по хэшу, остальные закреплены по версии. Если нужна полная изоляция, скачай их в папку проекта.
- Код подключения телефона не меняется, пока ты не удалишь файл `.lockin/token` и не перезапустишь сервер.
- Не открывай порт 5174 в интернет и не пробрасывай его через роутер.

## Нашёл уязвимость
Напиши владельцу репозитория напрямую, не в открытые обсуждения.
