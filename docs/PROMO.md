# Как снять ролик про Lock In

## Подготовка (2 минуты)
1. Запусти приложение: `Lock In.command`.
2. Открой `http://localhost:5173/?demo`. В углу появится жёлтая плашка DEMO: это пример истории (83 сессии, уровень 13, 15 достижений). Ничего не сохраняется и твои настоящие данные не затрагиваются. Плашку можно обрезать в монтаже.
3. Chrome, окно примерно 1280×800, масштаб 100%, тёмная тема системы не нужна.
4. Подключи телефон по QR-коду заранее.

## Кадры, которые работают лучше всего
| Кадр | Что показать | Почему цепляет |
|---|---|---|
| 1. «Телефон» | Возьми телефон в руки: на видео красная рамка, учитель вслух: «Телефон. Положи его» | Главная боль зрителя, видно за 2 секунды |
| 2. «Соцсети» | Открой Telegram: плашка «НЕ ПО ЗАДАЧЕ», учитель называет приложение | Ощущение, что за тобой следят |
| 3. «Можно в туалет?» | Напиши или скажи учителю: он спорит и не разрешает каждый раз | Живой диалог, не «ещё один таймер» |
| 4. «Объясни, чтобы отдохнуть» | Проверка объяснением: 60 секунд говоришь, потом вопрос | Необычная механика |
| 5. «Табель» | Конец сессии: печать оценки падает на бумагу, синяя ручка учителя | Самый красивый кадр, делай его крупным |
| 6. «Карточка» | Кнопка «Скачать карточку» и готовая картинка для сторис | Зритель сразу видит, что можно показать друзьям |

## Хуки для первых 2 секунд
- «Этот ИИ орёт на меня, когда я лезу в телефон»
- «Я попросился в туалет. Он отказал»
- «Моя оценка за сегодня: D. Учитель недоволен»
- «Попробовал работать 50 минут под наблюдением ИИ»

## Технические советы
- Записывай экран на Mac: ⌘+Shift+5. Для вертикального ролика обрежь по центру 9:16.
- Включи голос учителя (звук системы), иначе пропадёт половина эффекта.
- Рукописные реплики учителя читаются на видео только крупно: приближай камеру монтажом.
- Всегда снимай с настоящей камерой и настоящим телефоном: режим `?demo` подменяет только историю на главном экране.
